# RTV HUD / Windows HUD asset kit

この手順は HUD 素材の編集・コンパイル用です。Windows 用サーバープラグインの導入手順はありません。
通常のサーバー導入では公開済みアドオンを使用してください。
Windows 環境での利用方法は配布ルートの [README](../../../README-ja.md) を参照してください。

1. キット全体を展開します。
2. CS2 Workshop Toolsで既存アドオン `rtv_hud` を開きます。
3. `Build-Live.cmd` を実行し、CS2のインストールフォルダーを指定します。
4. 成功を確認します。既存 Workshop **3797394226** の公開者が素材を更新する場合は、公開内容を確認して更新します。
5. 素材を更新した場合は、サーバー側で新アセットを取得してから表示を確認します。

新規パス: `browser_scroll.vxml_c` / `browser_scroll.vcss_c`。
この版はページャーなしです。最初のティアだけが開き、全マップを同じ一覧でスクロールできます。
マップ名・ティア・G・IDは共通枠に含まれず、サーバーのmaplist.txtから設定されます。
更新後は364マップ、初期T1のみ展開、T2を開いた時に32件より先も表示できることを
確認してください。検索して先頭ティアが変わる場合と、検索解除後の状態も確認してください。
このキットはコンパイル用ソースです。Windowsコンパイルはまだ行っていません。
